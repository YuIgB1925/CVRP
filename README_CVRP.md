# CVRP — генетический алгоритм

Решение задачи маршрутизации транспорта с ограничением грузоподъёмности (Capacitated Vehicle Routing Problem) на Python. Алгоритм ищет маршруты с минимальной суммарной длиной, учитывая спрос клиентов и вместимость машин. Каждый маршрут начинается и заканчивается на складе.

## Алгоритм

Начальная популяция формируется из случайных и жадных решений. Далее применяются отбор, сохранение лучших особей, скрещивание и мутации: обмен клиентами между маршрутами и разворот участка маршрута.

## Запуск

Требуется Python 3. Сторонние библиотеки не нужны.

```bash
git clone https://github.com/YuIgB1925/CVRP.git
cd CVRP
python3 main.py
```

По умолчанию обрабатываются задачи из `Data/P`. Для каждой выводятся время выполнения, длина найденных маршрутов и отклонение от стоимости решения из соответствующего файла `.sol`.

Настройки задаются в `main.py`:

- `pth` — каталог с данными;
- `pop_size=75` — размер популяции;
- `elite_size=10` — число сохраняемых лучших решений;
- `mutation_rate=0.19` — вероятность мутации;
- `generations=10000` — число поколений; для быстрого запуска можно уменьшить.

## Структура

- `main.py` — запуск и сравнение результатов.
- `genetic.py` — генетический алгоритм.
- `models.py` — чтение `.vrp`, проверка решений и расчёт расстояний.
- `Data/` — наборы задач и эталонные решения.
- `B.csv`, `E.csv`, `P.csv` — сохранённые результаты экспериментов.
- `conv.py` — вспомогательное преобразование логов в CSV.

Алгоритм стохастический и не гарантирует нахождение оптимума. Расстояния вычисляются как евклидовы без округления.
